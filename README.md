# Веб-приложение «Список сотрудников»

Полнофункциональное клиент-серверное приложение для ведения справочника сотрудников.

## Стек технологий

- **Frontend:** React 19, TypeScript, Vanilla CSS
- **Backend:** Node.js, Express 5, TypeScript
- **База данных:** SQLite (`better-sqlite3`)
- **Безопасность:** хеширование паролей `bcryptjs`, аутентификация по Bearer JWT
- **Тестирование и CI:** Vitest, React Testing Library, Supertest, GitHub Actions

## Архитектура проекта

Проект организован как монорепозиторий (`npm workspaces`):

- `shared/` — общие TypeScript-типы, константы и валидаторы, переиспользуемые на клиенте и сервере.
- `server/` — слоистый REST API (`controllers` → `services` → `repositories` → `db`), middleware проверки токена и валидации, идемпотентный сидинг 5 демонстрационных сотрудников.
- `client/` — SPA на React с разделением логики и презентационных компонентов.

## Демонстрационный доступ

При первом запуске база данных автоматически инициализируется и наполняется 5 демонстрационными сотрудниками и тестовой учётной записью:

- **Email:** `demo@company.ru`
- **Пароль:** `Demo1234!`

На странице входа также доступна кнопка **«Заполнить демо-доступ»** для быстрого входа.

## Запуск приложения

### Вариант 1. Через Docker Compose

В корне репозитория выполните:

```bash
docker compose up --build -d
```

Приложение будет доступно по адресу: `http://localhost:4000`

База данных SQLite хранится в именованном Docker-томе (`sqlite_data`).

Остановка контейнера:

```bash
docker compose down
```

### Вариант 2. Локальный запуск для разработки

Требуется **Node.js >= 20**.

1. Установите зависимости всех пакетов из корня монорепозитория:
   ```bash
   npm ci
   ```
2. Запустите сервер разработки API (порт `4000`):
   ```bash
   npm run dev --workspace=@app/server
   ```
3. В отдельном терминале запустите клиент разработки Vite (порт `5173` с проксированием `/api` на `localhost:4000`):
   ```bash
   npm run dev --workspace=client
   ```
4. Откройте в браузере `http://localhost:5173`.

### Проверка типов, тесты и сборка

```bash
npm run typecheck
npm test
npm run build
```

## Использование ИИ при разработке

При выполнении задания использовалась модель **Claude**:

- **Проектирование архитектуры:** декомпозиция монорепозитория на пакеты `shared`, `server` и `client`, проектирование схемы SQLite, контрактов REST API и изоляция бизнес-логики фронтенда.
- **Разработка через тестирование (TDD):** генерация модульных и интеграционных тестов для валидаторов, репозиториев, эндпоинтов авторизации и пользовательских сценариев интерфейса.
- **Отладка и инфраструктура:** решение особенностей регистронезависимого поиска кириллицы в SQLite (`lower_utf8`), настройка конфигураций TypeScript 7 для монорепозитория.
